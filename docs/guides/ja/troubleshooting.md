## 値がない結果を理解する

解析は null を返すことがあります。郵便番号や市区町村の検索は、説明に応じて null、undefined、空の一覧を返します。既知の一致がない意味で、地域を推測してよい意味ではありません。一覧は失敗した番号に null を保ちます。入力欄の `address` は空か解析できないと null、`validation` は空か無効だと null です。任意の項目は見つかるまでありません。書式や国の確認に渡す前に、結果を確かめます。

## 国と型の選択を解決する

AU・GB・FR・DE は主な解析にモジュールを渡します。`country` の文字列だけでは表は読み込まれません。すべてを米国の形に型変換せず、国の項目を読みます。`useSnakeCase` は実際の項目名を変えますが、元の型は camel-case の項目です。[解析の説明](parsing.md)で動的な項目の読み方を示します。先頭の0や全角の正規化の選択を保ちます。

## フォームを調べる

必須で空の項目は無効で、任意で空の項目は有効のことがあります。確認を無効にしても端末の中で解析できます。無効な項目は送信せず、iframe の項目は親のフォームに送信できません。フォームの中で標準の要素を使い、`checkValidity` と `reportValidity` を読みます。イベントや設定 URL に文章がない場合は、私的な値を保つ境界です。信頼する表示側の取得やコールバックで読みます。[入力欄の詳細](form-field-and-embeds.md)を読めます。
